# 경관 후보 품질 평가 기준

> 상태: 실제 주행 검증 전의 임시 PoC 기준
>
> 적용 대상: 출처·이용권한 검수를 마친 경관 후보

## 1. 평가 항목

각 항목은 1~5점으로 기록합니다. `VERIFIED`로 추천에 사용할 후보는 세 항목이 모두 3점 이상이어야 하며 점수 근거를 `quality_review_note`에 남깁니다.

| 항목 | 1점 | 3점 | 5점 |
|---|---|---|---|
| 테마 적합성 `theme_fit_score` | 선택 테마를 주행 중 확인하기 어렵거나 다른 테마에 가까움 | 일부 주행 구간에서 선택 테마가 분명함 | 주행 구간의 주된 인상이 선택 테마와 일관됨 |
| 풍경 품질 `scenic_quality_score` | 풍경이 대부분 가려지거나 일반적인 도로와 구분하기 어려움 | 식별 가능한 경관 구간이 있으나 짧거나 단절됨 | 특징적인 풍경이 비교적 길고 연속적으로 드러남 |
| 경유지 적합성 `route_suitability_score` | 일반 승용차 경유지로 사용하기 어렵다고 판단됨 | 내비 경유지로 사용할 수 있으나 진입·회차 등 확인 사항이 있음 | 일반 승용차가 통상적인 경로로 접근하기 쉽고 경유 목적이 분명함 |

2점과 4점은 각각 인접 기준의 중간 상태로 판단합니다. 1~2점 후보는 `PENDING` 또는 `REJECTED`로 관리하고 추천에 사용하지 않습니다.

## 2. 후보 우선순위

세 점수의 합계(최소 9점, 최대 15점)를 동일 가중치로 사용합니다.

```text
후보 품질 합계 = 테마 적합성 + 풍경 품질 + 경유지 적합성
```

- 합계가 높은 후보를 먼저 외부 경로 계산 대상으로 전달합니다.
- 합계가 같으면 DB 식별자 순으로 정렬해 결과를 안정적으로 유지합니다.
- 이 점수는 TMAP 계산에 사용할 후보 우선순위를 정합니다. 계산이 끝난 LIVE 결과는 희망 시간과 가까운 순으로 모두 표시합니다.
- 실제 검수 데이터가 쌓이면 항목별 가중치와 최소 점수를 다시 조정합니다.

## 3. 검수 주의사항

- `route_suitability_score`는 실시간 안전, 도로 통제, 기상 또는 교통 상황을 보증하지 않습니다.
- 장소 도착 후의 전망만 좋고 주행 중 풍경이 보이지 않으면 높은 풍경 점수를 주지 않습니다.
- 지도 이미지나 외부 경로 API 응답을 장기 저장해 점수 근거로 사용하지 않습니다.
- 점수 근거에는 개인정보, 실제 사용자의 위치나 이동 이력을 기록하지 않습니다.
- 최종 후보는 가능하면 Pleos 내비 전달과 실제 또는 에뮬레이터 경로를 별도로 확인합니다.
