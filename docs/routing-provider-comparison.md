# 외부 자동차 경로 API 비교

> 확인일: 2026-11-01
> 상태: 공식 공개 문서 조사 완료 / 제공자 미선정 / 계정·키·결제 연동 없음

## 결론

첫 실제 경로 PoC는 **TMAP Free를 우선 검토하는 안**을 제안합니다. `just go` MVP가 1~2개 경유지를 사용하는 동안 다중 경유지 30의 일 100건 무료 한도로 개발 검증이 가능하고, 무료 한도 초과 시 자동 차단된다는 공식 안내가 있어 의도하지 않은 과금 위험을 비교적 명확하게 통제할 수 있기 때문입니다.

다만 TMAP 응답 데이터는 저장 후 24시간 이상 사용할 수 없으므로 경로 원본을 DB에 영구 저장하지 않습니다. 계정 생성, 앱 키 발급, 실제 API 호출도 사용자의 제공자 선택과 무료 범위 사용 승인 전에는 진행하지 않습니다.

## 업체별 확인 내용

### 1. TMAP API

- 자동차 경로안내와 다중 경유지안내를 제공합니다.
- TMAP API 약관은 다중 경유지를 순서가 정해진 최대 30곳으로 설명하고, 다중 경유지안내30을 일 100건 무료로 안내합니다.
- SK open API 요금 페이지는 Free 한도 초과 시 자동 차단된다고 명시합니다.
- 같은 페이지의 Premium 단가는 자동차 경로 11원/건, 다중 경유지 30은 22원/건이며 VAT 포함으로 표시됩니다.
- 약관상 TMAP API로 얻은 데이터는 저장 후 24시간 이상 사용할 수 없습니다.
- 상품 소개에는 30/100/200 경유지 상품이 보이지만 약관의 기본 설명은 30곳이므로, 실제 PoC는 프로젝트에 필요한 1~2개만 사용하고 상품 계약 범위를 앱 키 발급 화면에서 재확인해야 합니다.

공식 문서:

- [TMAP API 약관](https://tmapapi.tmapmobility.com/terms.html)
- [SK open API TMAP 요금](https://openapi.sk.com/products/calc?menuSeq=5&svcSeq=4)
- [TMAP API 상품·기능](https://openapi.sk.com/products/preview/tmap?menuSeq=4&svcSeq=4)

### 2. 카카오모빌리티 길찾기 API

- 자동차 길찾기는 최대 5개, 다중 경유지 길찾기는 최대 30개 경유지를 지원합니다.
- 공개 쿼터는 자동차 일 10,000건, 다중 경유지 일 5,000건입니다.
- 무료 쿼터 초과 가격은 자동차 8원/건, 다중 경유지 16원/건으로 공개되어 있습니다.
- 시작 문서는 카카오디벨로퍼스 앱 생성과 REST API 키 발급 절차를 안내합니다.
- 동시에 공식 `제휴 API` 페이지는 자동차 길찾기 API 사용 전 사전 제휴 계약이 필요하다고 명시합니다. 따라서 단순 앱 키 발급만으로 사용할 수 있다고 가정하지 않습니다.
- 응답 저장·캐시·재배포 범위는 공개 제품 문서에서 명확히 확인하지 못했으므로 제휴 계약/약관 확인 전 영구 저장하지 않습니다.

공식 문서:

- [길찾기 API 시작하기](https://developers.kakaomobility.com/guide/navi-api/start.html)
- [카카오모빌리티 쿼터 및 가격](https://developers.kakaomobility.com/price/)
- [제휴 API 이용 안내](https://developers.kakaomobility.com/affiliate/)

### 3. NAVER Cloud 신규 Maps

- 신규 `Maps` 상품의 Directions 5는 최대 5개, Directions 15는 최대 15개 경유지를 지원합니다.
- 대표 계정 한정 무료 이용량은 Directions 5 월 60,000건, Directions 15 월 3,000건으로 안내됩니다.
- 신규 Maps 상품 페이지는 무료 한도 초과 구간의 가격을 `-`로 표시합니다. 자동 차단인지 별도 계약인지 공개 정보만으로 확정하지 않습니다.
- 기존 `AI NAVER API` 안의 지도 API는 2026-11-24 종료 예정입니다. 새 프로젝트는 구형 상품이나 구형 키를 사용하지 않고 신규 Maps만 검토해야 합니다.
- NAVER Cloud 상품 신청은 과금 계정과 연결될 가능성이 있으므로 계정 생성·결제수단 등록·상품 신청을 자동으로 진행하지 않습니다.
- 응답 저장·캐시·재배포 범위는 별도 약관 확인 전 영구 저장하지 않습니다.

공식 문서:

- [신규 Maps 상품](https://www.ncloud.com/product/applicationService/maps)
- [Maps 개요](https://guide.ncloud-docs.com/docs/maps-overview)
- [Directions 5 안내](https://guide.ncloud-docs.com/docs/maps-direction5-api)
- [구형 지도 API 종료 일정 변경 공지](https://www.ncloud.com/support/notice/all/2200)

## PoC 진행 시 안전 기준

1. 사용자가 업체와 무료 범위 사용을 명시적으로 선택한 뒤에만 계정·앱 키 단계를 진행합니다.
2. 결제수단 등록, 후불 종량제, 유료 플랜, 제휴 계약 비용이 나타나면 진행을 중지하고 예상 비용과 무료 대안을 보고합니다.
3. 키는 백엔드 환경변수로만 주입하고 `.env`, 소스, Android APK, 로그, 문서에 기록하지 않습니다.
4. Provider에는 connect/read timeout, 호출량 상한, 응답 좌표·시간·거리 검증, 오류 분류를 둡니다.
5. 원시 경로 응답은 DB에 저장하지 않습니다. TMAP은 필요한 일시 메모리 사용만 하고 24시간 제한을 넘기지 않습니다.
6. 실제 사용자 위치 대신 명백한 테스트 좌표를 사용하고 요청·응답 원문을 로그에 남기지 않습니다.

## 사용자 결정 필요

- **제안 A:** TMAP Free로 첫 PoC 진행. 무료 한도 초과 자동 차단, 일 100건 다중 경유지 한도, 24시간 저장 제한을 적용합니다.
- **대안 B:** NAVER Cloud 신규 Maps 사용. 무료 한도 초과 처리와 결제 조건을 콘솔/문의에서 먼저 확인해야 합니다.
- **보류 C:** 카카오모빌리티 제휴 계약 가능 여부를 먼저 문의한 뒤 검토합니다.

제공자가 선택되기 전에는 `DrivingRouteProvider`의 현재 `MOCK`/`UNAVAILABLE` 구현을 유지합니다.
